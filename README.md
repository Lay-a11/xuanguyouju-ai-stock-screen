# 选股有据

通过对话帮助用户理解并明确自己的选股意图，再把双方确认的标准转化为可检查、可修改、可执行的数据条件，使用真实金融数据解释筛选结果。

## 在线产品

- 产品地址：<https://xuanguyouju-ai-stock-screen.epic-hinny-6834.chatgpt.site/>
- 源代码仓库：<https://github.com/Lay-a11/xuanguyouju-ai-stock-screen>
- 最终提交版本：对话式策略澄清流程
- 股票池：20 家沪深跨行业固定演示样本，不代表全 A 股

## 本地运行

本项目为无构建步骤的静态 Web 应用：

```bash
python3 -m http.server 4173 --directory dist
```

打开 <http://localhost:4173>。

运行验收检查：

```bash
npm test
```

重新抓取扶摇数据：

```bash
FUYAO_API_KEY='<your-key>' npm run refresh-data
```

环境变量只在数据刷新进程中使用。Key 不写入网页、数据快照、文档或仓库。

## 产品主链路

1. 用户用自然语言描述想找的公司。
2. 语义层复述理解，只追问含义不明确的部分。
3. 先确认“经营改善、价格合理、走势稳定”具体指什么，再共同确定阈值。
4. 用户可以点击选项、直接输入数字，也可以询问概念含义。
5. Chat 内生成最终策略总结；“精细调整”展开同一份结构化策略。
6. 确定性引擎用 AND 组合执行，返回符合、未通过、信息不足三类结果。
7. 每只股票可查看条件、实际值、原始金额、报告期、行情时间、抓取时间和请求追踪 ID。
8. 修改同一策略后再次执行，可查看同一快照下的结果变化；可保存到浏览器 localStorage。

## AI、筛选引擎与数据职责

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| 受限语义解析层 | 识别当前支持的意图、解释概念、生成澄清流程与结构化条件 | 不生成金融事实，不直接决定名单 |
| 确定性筛选引擎 | 冲突检查、逐项比较、三态判定、条件变化影响 | 不自动放宽条件 |
| 同花顺扶摇 API | 行情、估值、利润表、历史日线 | 不替产品解释用户意图 |
| 用户 | 确认含义与阈值、精细修改 | 系统不会暗中替用户改变标准 |

当前运行时没有接入通用大模型，使用可审查的受限语义解析器完成演示。界面已明确显示“受限语义解析演示”，不将关键词规则包装成完整 LLM。

## 数据来源与口径

- 行情快照：最新价和行情时间。
- 估值快照：PE TTM、PB MRQ；倍数比较仅使用正值。
- 财务：扶摇整体合并利润表，使用最新报告期与上年同一报告期的营业收入、归母净利润。
- 波动率：21 个有效前复权收盘价生成 20 个对数日收益率，样本标准差按 252 个交易日年化。
- 基期非正、字段缺失、接口异常时返回不可验证，不强行计算正常增长率。

本版本未使用 iFinD MCP。题目允许的数据并不要求全部使用；当前核心条件可由扶摇完整支持。市场宽度、资金、宏观、政策与新闻不是本次核心主链路的必要输入，未为“看起来数据多”而堆叠。

## 安全与合规

- 不包含 API Key、用户隐私或持仓数据。
- 不输出直接买卖建议、确定性涨跌预测或收益承诺。
- 不支持的现金流、行业相对估值、ROE、股息等需求会明确提示，不用其他指标静默替代。
- 页面中的研究结果不是投资建议。

## 已知边界与未做事项

- 固定 20 家演示股票池，不覆盖全市场。
- 受限语义解析器不能理解任意表达。
- 未实现公司并排比较、回测、监控、交易、账户级云端保存。
- 已实现题目要求后续动作中的“保存”；题目表述为比较、保存、回测或监控，未要求全部实现。
- 数据为带时间戳快照，不能当作实时行情。
